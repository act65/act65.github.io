<!-- Frame: an impossibility theorem is a list of assumptions that cannot all hold.
     So it is also a menu. Each assumption you drop is a research programme. -->

| Escape | What is given up | Where it leads |
|---|---|---|
| Randomise | determinism | random dictatorship, maximal lotteries, sortition |
| Restrict the domain | universality | single-peaked preferences, generalised medians, ballot design |
| Go cardinal | ordinality and non-comparability | score voting, quadratic voting, social utility functions |
| Approximate | exactness | distortion |
| Make manipulation hard | worst-case guarantees | complexity barriers |
